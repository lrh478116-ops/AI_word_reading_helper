AI Tip 隐私政策

生效日期：2026 年 8 月 30 日　最后更新：2026 年 8 月 30 日

本政策说明 AI Tip Windows 与 macOS 桌面应用如何处理信息。AI Tip 默认以本地模式工作：不点击“上传到云端”，文档、Tip 对话和设置就只保存在当前设备。公开网站不使用广告、统计脚本或跟踪像素。

2. 本地保存与云端上传

导入文档不会自动上传。只有用户登录云账户并点击“上传到云端”后，应用才会把文档快照、Tip 数据以及原文件的 gzip 压缩包上传到 Supabase。每个用户的云端空间限额为 5 MB；达到限额时上传会被拒绝，本地文件仍保留。关闭应用、切换页面或普通本地删除不会被描述为云端删除。

3. 大模型、Tavily 与其他第三方

AI Tip 不向其他用户提供开发者的私有大模型 API Key。用户在设置中自行录入大模型 API 后，问题、相关原文、Prompt 和必要上下文会发送给该用户选择的 API 提供商。使用本地模型时，这些推理数据在本机处理。

联网搜索默认关闭。关闭时，不调用 Tavily，也不访问百科或其他参考网站；打开后，搜索词可能发送至 Tavily 或相关参考站点。第三方如何使用信息受其自身条款和隐私政策约束。搜索失败时应用仍可基于已导入文档回答，但会明确说明证据边界。

4. 凭据安全

选择“记住登录”时，登录凭据通过操作系统提供的安全存储或加密能力保存在当前设备。模型 API Key 与 Tavily Key 不上传到 AI Tip 的 Supabase 文档库。请勿在共享设备上启用记住登录，并妥善保护设备账户。

5. 保留、导出和删除

本地数据会保留到用户在应用中删除文档、清除本地账户数据或卸载并移除应用数据。云端数据会保留到用户移出云端或删除账户。删除云账户时，应用先删除该用户的云端 Storage 对象，再删除 Auth 用户；数据库中的文档与 Tip 通过所有者关系级联删除。详情见删除账户说明。

6. 权限与选择

用户可选择仅本地使用、是否创建云账户、是否上传具体文档、是否启用联网搜索、使用本地模型或第三方模型，以及是否记住登录。导入文件与选择模型目录时，应用仅访问用户明确选择的路径。

7. 儿童、跨境与变更

AI Tip 面向能够理解文档分析和外部 API 配置的用户，不以儿童为目标。用户选择境外 AI 或搜索服务时，相关数据可能在其服务区域处理。政策发生实质变化时，将在本页更新日期，并在适用情况下通过应用提示。

AI Tip Privacy Policy

Effective and last updated: August 30, 2026

AI Tip is a Windows and macOS desktop document reader. It is local-first: documents, Tips and settings remain on the current device unless you explicitly select Upload to cloud. This website does not use ads, analytics or tracking pixels.

Information and purposes

If you create a cloud account, Supabase Auth processes your name, email and authentication state. Imported documents, parsed structures, edits, Tip anchors, conversations and memory settings are processed to provide reading and AI features. AI provider settings, prompts and API credentials are stored on your device.

Cloud storage

Cloud upload is opt-in per document. A compressed source archive, document snapshot and Tip data are stored in Supabase, with a 5 MB per-user quota. Model and Tavily API keys are excluded from that cloud document store.

AI and web search

When you choose an external AI provider, relevant prompts and document context are sent to that provider. Web search is off by default. When enabled, queries may be sent to Tavily or displayed reference sites. Local models process inference on your device.

Security, retention and deletion

Remembered login data uses operating-system secure storage or encryption. Local data remains until removed on the device. Cloud data remains until removed from cloud or the account is deleted. See the account deletion instructions.
