# AI Tip 1.12.12 云账户网络修复

- 认证、云文件与搜索使用桌面系统网络绑定，修复 Supabase 绕过 Chromium 的路径。
- 修复 Chromium POST/PATCH 请求体丢失，以及 HEAD/204/取消和手动重定向。
- 注册、验证码、恢复和登录显示可区分的云网络错误；429 不再被当作密码错误。
- 桌面绑定缺失明确报错；云请求禁止跨域重定向携带身份；不自动重放注册和验证码。
- 新增 `pnpm cloud:network:test`（离线协议回归）与 `pnpm cloud:connection:test`（正式桌面真实服务探针，无注册或发邮件）。后者依赖当前生产项目和网络可达性。

2026-09-10 已恢复原 Supabase 项目。免费版仍可能在低活动时暂停，生产可用性与客户端版本分开验收。真实邮件与当前网络可达性未取得证据前不得宣称全流程通过。Windows 包仍使用现有未签名分发配置。
