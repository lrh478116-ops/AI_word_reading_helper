# AI Tip 1.12.11 发布说明

## 用户可见变化

- 支持、隐私政策和账户删除说明改为公开可访问的正式 HTTPS 页面。
- 新注册和密码重置最低要求提高到 8 位；已有账号仍可正常登录。
- 保留本地优先：文档默认不上云，只有点击“上传云端”才上传压缩副本；单用户云空间仍为 5 MB。
- 继续支持删除单篇文档的云端文件，以及在设置中永久删除云账户。

## 安全与分发

- Electron 主窗口改用精确 origin 校验，阻止字符串前缀、不同端口、user-info 伪装和非 HTTP(S) 导航绕过。
- 新增 CSP；只为离线 OCR 和 Python 精确计算开放 WebAssembly 编译，不开放普通 JavaScript `unsafe-eval`。
- 修复构建链 `nanoid` 高危版本，完整与生产依赖审计均为零告警。
- 安装包包含第三方许可清单和 Windows llama.cpp 主许可证。
- 主源码仓库以 MIT 许可证公开，应用许可证也随 Windows/macOS 安装资源分发。
- 明确声明 macOS 12.0 为当前最低兼容版本；Electron 保持 43.x，不升级到会移除 macOS 12 支持的主版本。

## 已验证

- TypeScript、构建、全部脚本回归和 Electron 桌面 smoke。
- PDF 原版式与 OCR Tip、Word 表格直接编辑、换行光标、递归 Tip、首条完整回答预览、10 MB 以上导入、联网关闭零请求、云同步失败隔离、删除云文件、账户删除负向路径、系统安全存储和 Python Decimal。
- 公开站点首页、隐私页与账户删除页均返回 HTTP 200。

## 尚未完成的外部发布事项

- Windows 安装器与主 EXE 尚无可信 Authenticode 签名。
- macOS universal 包必须在 Mac 上使用真实 Apple 证书和 provisioning profile 构建、验证沙箱并上传 App Store Connect。
- 真实 SMTP 注册/恢复邮件与私密审核账号仍需运营者验证。
- ICP/APP 备案、Apple 运营主体/电话/出口合规/交易者状态必须由真实主体填写，不能从代码生成。
