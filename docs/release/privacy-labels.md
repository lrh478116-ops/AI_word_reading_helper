# App Privacy 数据标签核对表

这是一份工程事实清单，不替代 App Store Connect 的最终问卷。提交前应在候选构建上抓取真实网络流量，并由运营者按 Apple 当时的字段定义确认。

| 数据类别 | 是否可能处理 | 用途 | 是否关联账户 | 是否用于追踪 | 条件与边界 |
| --- | --- | --- | --- | --- | --- |
| 姓名 | 云账户模式是 | 账户功能 | 是 | 否 | 仅用户创建云账户时 |
| 邮箱地址 | 云账户模式是 | 认证、验证码、恢复 | 是 | 否 | Supabase Auth 与邮件服务处理 |
| 用户内容：文档 | 是 | 核心阅读、AI 回答、可选同步 | 可选 | 否 | 默认本地；显式上传或外部 AI 调用时离开设备 |
| 用户内容：聊天/Tip | 是 | 核心功能、可选同步 | 可选 | 否 | 默认本地 |
| 搜索查询 | 可选 | 联网搜索 | 可选 | 否 | 开关默认关闭；打开时由 Tavily/参考站点处理 |
| 诊断数据 | 当前不由官网收集 | 本地故障排查 | 否 | 否 | 若以后引入崩溃服务，必须先更新政策和问卷 |
| 标识符 | 账户 UUID | 云数据隔离与同步 | 是 | 否 | 不用于跨产品广告追踪 |
| 支付信息 | 否 | — | — | — | 当前无应用内购买 |
| 精确位置、通讯录、照片库、健康数据 | 否 | — | — | — | 当前实现不请求这些权限 |

## 第三方处理者

- Supabase：仅云账户、认证、验证码、显式上传的数据与账户删除。
- 用户选择的大模型 API 提供商：处理问题、Prompt 与为回答所需的文档上下文。
- Tavily 或参考站点：仅联网搜索开关打开时处理查询。
- Ollama / 内置本地运行时：在设备上推理；模型文件从用户选择的官方或镜像来源下载。

## 提交前反事实检查

1. 关闭联网搜索后，抓包中不得出现 Tavily、百科或搜索站点请求。
2. 不点击“上传到云端”时，导入、编辑和 Tip 聊天不得向 Supabase Data API/Storage 写入。
3. 未配置外部模型并使用本地模型时，推理正文不得发送给外部模型 API。
4. 移除 Google Fonts 后，冷启动不得访问 Google Fonts 域名。
5. 删除账户后，旧 access token 不得通过应用正式 API；Storage RLS 还必须检查 Auth 用户仍存在。
