# 中国大陆 ICP / APP 备案资料清单

状态：`KNOWN_FRAMEWORK_GAP`（需要真实运营主体、域名、境内接入资源和主管部门流程，代码不能代办或伪造）。

## 运营者需要确认

- 主体类型：个人 / 企业 / 其他组织。
- 主体法定名称、证件类型与号码、证件地址。
- 负责人姓名、证件、手机号、应急联系电话和核验材料。
- 正式域名、域名注册人、域名实名认证状态。
- 中国大陆服务器/接入商、服务区域、IP 或云资源实例。
- APP 名称、图标、包名/Bundle ID、平台（Windows/macOS 等）、SDK 清单与隐私政策 URL。
- 是否包含新闻、出版、教育、医疗、金融、宗教、地图等需要前置许可的业务。

## 建议顺序

1. 确定真实运营主体和正式域名，不使用 GitHub Pages 地址作为中国大陆备案域名的替代证明。
2. 通过实际境内接入服务商提交网站 ICP 备案资料并完成核验。
3. 按主管部门/应用分发平台要求提交 APP 备案信息，使 APP 名称、包名、主体和域名保持一致。
4. 取得真实备案号后，才在官网页脚和适用客户端位置展示；链接到主管部门指定查询入口。
5. 每次更名、换主体、换域名、改包名或停止服务时，核对是否需要变更/注销备案。

## 发布门禁

- 未取得真实编号：官网与配置只能保留“备案待运营者完成”的内部说明，不得展示假号。
- 只完成网站 ICP 不等于 APP 备案已经完成。
- 境外托管能访问不等于满足中国大陆上线要求。
- 最终商店地区选择、许可证问卷和合同责任由真实运营主体确认。
