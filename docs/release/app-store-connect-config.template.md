## 中文描述草案

AI Tip 是一款面向深度阅读的 Windows 与 macOS 桌面应用。导入 PDF、Word、Markdown 或文本文件，选中原文即可在旁边创建 Tip 对话。每个 Tip 独立保存，也可通过可控记忆相互协作；子 Tip 与树状导航帮助你逐层追问并随时返回原文。

文档默认仅保存在本机。只有你主动点击“上传到云端”时，应用才会上传压缩副本；联网搜索也默认关闭。你可以使用自己的大模型 API、本机 Ollama，或在应用中下载兼容的轻量本地模型。

主要功能：

- PDF 原始页面文字选择、坐标锚定 Tip 与扫描页 OCR；
- Word 表格和文档结构阅读，文本可直接编辑并自动保存；
- 递归 Tip、共享记忆、Tip 树、重命名和定位；
- 专业程度判断、可选联网核验、Python 数值计算；
- 本地优先保存、按文档显式云上传和 5 MB 云空间上限；
- 简体中文与英文界面。

## 审核说明草案

1. 应用可以不创建云账户：在登录页点击“仅本地使用”，即可导入文档、创建 Tip 并体验本地核心流程。
2. 本地体验账户只存在于当前设备，不代表 Supabase 云测试账户。
3. 如果审核云同步、注册验证码和云账户删除，请使用 App Store Connect“Sign-in required”区域中单独提供的私密测试账号；不要把凭据写入本文件或仓库。
4. 文档不会自动上传。打开文档后，必须点击“上传到云端”才会产生云副本。
5. 联网搜索默认关闭，可在设置或对话输入框纸飞机旁打开。
6. 删除云账户路径：设置 → 账户与隐私 → 删除账户。仅本地模式显示“清除本地账户数据”。
7. 若没有配置外部模型 API，可在设置中选择本地模型；审核期间如不测试模型下载，应在私密审核说明提供已配置环境和准确操作步骤。
