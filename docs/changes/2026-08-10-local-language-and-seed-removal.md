# 本地入口、显式登出、语言切换与示例文档移除

## 已确认问题

1. 登录页的本地演示账户入口显示为“直接进入演示”，没有表达数据仅在本机使用。
2. 退出登录动作已真实清除会话，但入口仅显示省略号图标，缺少明确动作文本。
3. UI 文案直接硬编码在 React 组件中，没有统一语言状态、持久化或正式下游消费。
4. Transformer 示例文档由服务端种子函数在首次启动和注册时创建；集成测试依赖该隐式 fixture。

## 设计不变量

- “仅本地使用”仍登录固定的本机演示账户，不得改成绕过鉴权的旁路。
- “退出登录”必须继续调用唯一正式会话清理路径，并立即返回登录界面。
- 登录页和设置页必须操作同一个根级语言状态；语言变化必须改变正式 UI 输出并持久化。
- 只移除可由完整结构签名识别的内置 Transformer 种子文档；允许其末尾存在空编辑块，但任何非空用户补充都必须保留。
- 新注册用户和新数据目录不得再自动创建示例文档。
- 测试必须显式创建所需文档，不能依赖种子数据。

## 非目标

- 不翻译用户文档、Tip 内容、模型回答、服务商名称或模型名称。
- 不改变登录协议、JWT、用户数据隔离或 AI 调用协议。
- 不删除标题相同但内容结构不同的用户文档。

## 验收条件

1. 非法语言值回退为简体中文；语言选择刷新后保持。
2. 登录页和设置页都能切换简体中文/English，文档库与编辑器立即跟随。
3. 本地入口显示“仅本地使用”/“Local use only”，点击后仍通过 `/api/auth/login` 登录本机演示账户。
4. 导航区显示显式“退出登录”/“Sign out”按钮，点击后 token 被清除且登录页重新出现。
5. 新数据目录启动后演示账户存在，但文档列表为空。
6. 注册新用户后文档列表为空。
7. 旧数据库中的未修改 Transformer 种子文档及其 Tip 被迁移删除；相似但不完全匹配的用户文档保留。

- `scripts/test-skills-integration.mjs`：正式启动迁移、正式登录、新用户注册为空、显式测试文档创建，以及 Tip/Python/联网技能主链通过。
- Electron 源码态烟测：真实点击中文/English、本地入口、设置语言、退出登录；确认 token 清除与新数据目录无 Transformer 文档。

## 接入等级结论

- 本地入口：`LEVEL_5_PREDICTION_BEARING`（点击后经 `/api/auth/login` 取得 token，正式文档请求成功）。
- 退出登录：`LEVEL_5_PREDICTION_BEARING`（点击后正式会话 token 被清除并返回登录页）。
- 语言切换：`LEVEL_5_PREDICTION_BEARING`（登录页和设置消费同一根状态，正式 UI 输出发生变化且状态持久化）。
- Transformer 种子移除：`LEVEL_5_PREDICTION_BEARING`（正式启动迁移改变持久化数据库；注册及首次启动不再产生样例文档）。
8. focused tests、完整技能回归、桌面冒烟测试和安装包内冒烟测试全部通过。
