## 实施边界与依赖顺序

先负向回归，再建立取消作用域和真实流式适配器，然后接入正式 chat；计算迁入单次 Worker 后接入文档预热；增加源文件大小、分块索引、检索与模型上下文依赖；最后验证 UI 与打包。

- 保留全部既有未提交改动；不修改云账户、数据库 schema 或搜索开关，不自动推送 GitHub。
- 原文件 > 10 MiB 或提取文字显著过长时启用本地 RAG。它是带来源定位的稀疏全文检索，不冒充向量语义检索；无需额外模型下载或 Embedding API。扫描 PDF 无文字时明确需 OCR，不伪造识别文字。
- 进入文档：本地分块/索引与一次性 Python 预热，不搜索互联网，不发送推理请求，不自动 OCR 全文；索引限定缓存容量，后台分批让出事件循环。
- 模型仍可能一次性返回 JSON：读取本次原响应并明确提示不支持流式，不重发相同生成请求；损坏分片、缺失工具参数或截断流不得静默降级或执行不完整动作。
- 专业审查/引用缓冲和无结果搜索恢复仍有效；需要审查的回答不提前展示。文字后出现工具调用时撤回本轮临时文字，不把规划前言当最终回答。
- 停止后禁止发起新模型/搜索/工具调用，主动中止 HTTP 和终止活动 Worker；未完成回答不写成完成消息。远端服务实际停止计算/计费取决于其取消支持，不作超范围保证。
- 证据严格分级：受控 SSE/模型 fixture 即便调用真实业务入口，也仅归为 COMPONENT_CAPABILITY；可记录它运行了哪些入口，不能用它替代正式真实模型集成和独立评估。RAG 必须用删除命中、修改文档、换问题/账号的反事实检查实际模型输入变化。

## 追加审计：测试环境隔离

整套回归的 Electron 云文件 UI 测试在默认共享 userData 下出现 library 超时；相同源码与同一测试使用全新临时 userData 后通过。没有据此改动 Supabase 或放宽业务断言。统一在该测试内建立独立配置目录，并在失败时输出页面诊断，防止多个 Electron 测试共享缓存影响验收。

## 证据边界与未作出的承诺

本地组件执行和受控提供方回归均属于 COMPONENT_CAPABILITY，不能据此宣称真实用户任务的 LEVEL_5 独立验收。实际生产 API 的首字延迟、语义检索召回率与正确率：NOT_CAUSALLY_VERIFIED。此次没有调用用户的付费模型或 Tavily 额度，也没有进行 macOS 真机/商店签名验收；Windows 安装包仍须如实检查并标注数字签名状态。

检索为本地中文二元词组/英文分词 BM25，不是向量检索；最多取 6 个约千字片段，索引缓存最多保留 3 个版本化文档，超过 120,000 分块会明确失败，不伪装成完整索引。扫描图片需要已有 OCR 文字。进入文档预加载不代表模型本身已预热；需要审查的输出仍缓冲。客户端停止会中止本地链路，但远端是否停止计算/计费依赖提供方实现。

流式分片实现参考 [OpenAI 官方函数调用文档](https://developers.openai.com/api/docs/guides/function-calling) 与本项目安装的 SDK；未以第三方镜像说明替代官方协议。
