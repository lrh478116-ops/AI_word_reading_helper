# 聊天内递归 Tip、可逆双栏布局与 Tip 树

## 已确认问题

1. `TipThread` 只保存文档块锚点；没有父 Tip、来源消息或消息内偏移，聊天选区无法进入正式持久化主链。
2. 消息正文没有选区事件和子 Tip 标签；现有 `SelectionToolbar` 只认识文档块。
3. 编辑器布局只有“文档 + 单个 Tip”，无法表示“父聊天替换文档、子聊天替换父聊天”的活动路径，也没有收回后的确定性恢复规则。
4. 删除接口只删除一个 Tip；增加父子关系后会留下孤儿子树。
5. `recoverAnchors` 把所有 Tip 都按文档块恢复；消息锚点会被错误标为 orphaned。
6. PATCH 已能更新标题，但没有树视图、节点定位和可编辑名称入口。
7. 当前聊天流状态没有绑定活动 Tip；导航到另一层时可能把流式文本显示在错误对话中。

## 设计不变量

- 根 Tip 使用 `anchorType=document`，继续锚定文档块；子 Tip 使用 `anchorType=message`，必须同时保存 `parentTipId`、`anchorMessageId` 和规范化显示文本内的精确偏移。
- 子 Tip 创建必须验证：父 Tip 属于当前用户、来源消息属于父 Tip、选区文字与消息显示文本完全一致、父链无循环且深度不超过 32。
- 消息正文的规范化显示文本是去除 `**` 强调标记并统一换行后的内容；前后文和偏移都基于同一规范化函数，避免 UI 与后端偏移语义不一致。
- 进入根 Tip：左侧是文档、右侧是根 Tip。进入子 Tip：左侧是它的父 Tip、右侧是当前子 Tip。继续进入更深层时按同一规则递归。
- 收回当前 Tip：如果有父 Tip，活动节点回到父 Tip；如果是根 Tip，回到文档单栏。不得依靠浏览器历史或临时 DOM 猜测恢复位置。
- 当前显示的每个聊天面板都允许从已持久化消息选区创建子 Tip；正在生成的临时消息不能作为锚点。
- 当前文档存在任意子 Tip时，在左上角显示 Tip 树按钮。树节点显示持久化标题、可点击定位、可编辑并通过正式 PATCH 接口保存。
- 删除任意 Tip 必须级联删除它的全部后代，并返回实际删除 ID；UI 根据返回 ID 更新，不得保留假节点。
- 子 Tip 的回答上下文读取来源消息与父 Tip 标题，而不是伪装成文档块上下文。
- 文档锚点恢复只处理根 Tip；消息锚点独立校验和恢复。父 Tip 或来源消息缺失时必须明确标为 orphaned，不能静默改挂到文档。
- 导航、收回或删除活动 Tip 时终止该 Tip 的流式请求，避免输出写到错误面板；服务端持久化仍以请求 Tip ID 为准。

## 非目标

- 不在第一版树视图中实现自由拖拽改父节点；这会改变上下文 lineage，需要单独设计。
- 不允许在树中修改系统 ID、父 ID、来源消息或锚点偏移。
- 不把子 Tip 全量消息自动共享给兄弟 Tip；原有“记忆”仍只共享摘要。
- 不允许跨文档或跨用户创建父子关系。

## 验收条件

1. 从根 Tip 的持久化消息创建子 Tip，返回对象真实包含父 Tip ID、消息 ID、消息锚点类型和正确偏移。
2. 从子 Tip 消息继续创建孙 Tip，深度与 lineage 可追溯；GET 文档后关系仍存在。
3. 消息不存在、消息不属于父 Tip、偏移不匹配、跨用户父 Tip、重复或重叠锚点以及超过 32 层时明确失败。
4. 文档锚点恢复不会把合法消息 Tip 标为 orphaned；删除来源消息或父节点的损坏 fixture 会把子 Tip标为 orphaned，而不是改挂。
5. 进入子 Tip 后左侧显示父聊天、右侧显示子聊天；进入孙 Tip后左侧显示子聊天、右侧显示孙 Tip。
6. 收回孙 Tip恢复“父聊天 + 子聊天”，再收回子 Tip恢复“文档 + 根聊天”，再收回根 Tip恢复文档单栏。
7. 任意可见持久化消息可创建子 Tip；新子 Tip 标签显示在选区附近并能重新打开。
8. 存在两级 Tip时左上角显示树按钮；树节点按父子层级展示名称，可定位并通过 PATCH 持久化改名。
9. 删除父 Tip级联删除所有后代，文档 Tip 数与 UI 树同步；删除其他用户或不存在的 Tip不影响当前树。
10. 旧数据没有新字段时迁移为根文档 Tip，不丢失历史消息。
11. 现有专业模型评估、政策联网、Tavily 免费额度、Python 数值、记忆隔离、建议箱和桌面 API 隔离回归通过。
12. Electron 源码态与 Windows 打包态烟测验证树按钮、双栏替换、收回还原、重命名和级联删除进入真实发布产物。

- 树导航与改名：树节点点击可分别定位根和子 Tip；节点保存按钮触发正式 PATCH，重新 GET 后标题保持修改值。

- 完整回归：TypeScript、Vite、服务端和 Python worker 构建，产品行为、嵌套 Tip、Python 数值、安全沙箱、高级技能、专业/政策联网、建议箱、API 隔离和 Electron 源码态烟测全部通过。

## 接入等级结论

- 消息选区创建子 Tip：`LEVEL_5_PREDICTION_BEARING`。消息选区字段被后端正式校验和持久化，并决定子 Tip 的回答上下文与最终输出。
- 递归父子 lineage：`LEVEL_5_PREDICTION_BEARING`。根、子、孙关系进入 GET、聊天上下文、布局、树导航、删除和发布包烟测；改变父 ID 会改变可见布局与聊天是否允许执行。
- 双栏替换与逐层还原：`LEVEL_5_PREDICTION_BEARING`。活动路径真实决定左右面板，根/子/孙的进入和收回均由 Electron UI 反事实验证。
- Tip 树定位与名称修改：`LEVEL_5_PREDICTION_BEARING`。树节点读取真实父子数据，点击改变活动对话，保存通过 PATCH 并经重新 GET 验证。
- 级联删除：`LEVEL_5_PREDICTION_BEARING`。服务端使用实际子树 ID 删除并返回 lineage，重新加载确认后代消失且无孤儿残留。
- 32 层安全上限与孤儿阻断：`LEVEL_5_PREDICTION_BEARING`。真实创建和聊天接口均有负向证据，不只停留在组件函数。
