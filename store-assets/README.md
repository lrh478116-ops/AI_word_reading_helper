# App Store 素材

`macos/zh-CN` 中的 PNG 必须由真实 Electron 候选构建捕获。Mac App Store 接受的截图尺寸包括 1280×800、1440×900、2560×1600 和 2880×1800，至少 1 张、最多 10 张。

本目录不接受生成式 UI 效果图冒充产品截图。捕获前使用公开或合成文档，检查画面中没有 API Key、审核密码、真实私人文件和邮箱验证码。

预览视频是可选项；若制作，按 `preview-storyboard.md` 使用真实 App 录屏并在 macOS 上导出符合 App Store Connect 当前规格的文件。
