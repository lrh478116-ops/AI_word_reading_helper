# macOS App 预览分镜（真实录屏）

建议时长 24–28 秒，横向 1920×1080；提交前以 App Store Connect 当时规格复核。视频只能展示真实运行中的 App。

| 时间 | 画面 | 操作 | 字幕草案 |
| --- | --- | --- | --- |
| 0–4 秒 | 文档库与拖放区域 | 将公开样例 PDF 拖入 App | 拖入 PDF、Word 或文本，自动保存当前工作 |
| 4–9 秒 | PDF 原始页面 | 选择一段文字并点击小型 Tip | 在原始版式旁创建 Tip |
| 9–15 秒 | Tip 聊天 | 提问并显示完整回答 | 解释、专业解释，保持原文上下文 |
| 15–20 秒 | 子 Tip 与树 | 选择回答中的术语创建子 Tip并展开树 | 逐层追问，随时返回 |
| 20–24 秒 | 设置 | 显示本地模型、联网开关与本地优先说明 | 本地优先，联网由你控制 |
| 24–28 秒 | 文档页 | 收回 Tip，恢复原文位置 | 阅读不被对话打断 |

## 捕获检查

- 使用测试文档和测试账户，不显示真实 API Key、密码、验证码或私人文件。
- 系统语言、应用语言、字幕语言和商店区域一致。
- 不展示尚未完成或不能复现的功能。
- 不在视频中承诺搜索“始终正确”或“100% 准确”。
