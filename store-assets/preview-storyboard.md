## 捕获检查

- 使用测试文档和测试账户，不显示真实 API Key、密码、验证码或私人文件。
- 系统语言、应用语言、字幕语言和商店区域一致。
- 不展示尚未完成或不能复现的功能。
- 不在视频中承诺搜索“始终正确”或“100% 准确”。
- 本轮没有生成或提交视频。必须在 Mac 签名候选包上录制，不用静态预览图拼成“真实录屏”。
- 生成等待不得剪辑成对速度的虚假承诺；如剪短等待，应明确提示演示有剪辑。
